# Animation skills

Group folder for web animation skills. Not a skill itself: each subfolder is an independent skill and installs on its own (`npx skills add <owner>/<repo> --skill <name>`).

Start with `motion-conventions` for our defaults, use the Emil skills for taste and review, and the `gsap-*` skills (in `skills/`) for the GSAP API.

| Skill | Source | Use when |
| --- | --- | --- |
| `motion-conventions` | first-party (display studio) | Scroll reveals, Lenis, page transitions, reduced motion; Nuxt and vanilla adapters |
| `emil-design-eng` | `emilkowalski/skills` (MIT) | Deciding whether/how to animate: easing, durations, springs, UI polish |
| `animate` | `emilkowalski/skills` | Building an animation from scratch |
| `review-animations` | `emilkowalski/skills` | Reviewing existing motion against a craft bar |
| `improve-animations` | `emilkowalski/skills` | Auditing a codebase's motion and writing fix plans |
| `find-animation-opportunities` | `emilkowalski/skills` | Finding places that should animate (read-only) |
| `animation-vocabulary` | `emilkowalski/skills` | Naming an effect precisely |
| `apple-design` | `emilkowalski/skills` | Gestures, velocity, momentum, Apple-style fluidity |

Vendored skills are overwritten by the weekly sync: do not edit them here (see `SYNC.md`).
